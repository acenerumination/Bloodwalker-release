# Bloodwalker - Videojuego de Supervivencia Zombie en 2D

![Unity Version](https://img.shields.io/badge/Unity-6%20(6000.0.6f1)-blue)
![Build](https://img.shields.io/badge/Build-v1.0.0--mvp-orange)

## 🧟 Resumen
Un juego de supervivencia zombi en 2D con vista top-down y arte pixelado. El jugador debe navegar a través de una instalación de 7 habitaciones conectadas por un pasillo central, enfrentarse a dos tipos distintos de zombis utilizando Magia de Sangre y encontrar la escotilla de escape para sobrevivir.

## 🎮 Descarga e Instalación
La compilación jugable más reciente está disponible en la [Página de Releases](https://github.com/acenerumination/Bloodwalker-release/releases).
1. **Descarga:** `Bloodwalker_v1.0.0_Windows.zip`
2. **Extrae** el archivo y ejecuta `Bloodwalker.exe`.
